## 작성 방법

- 파일명은 직관적인 한글로 짓고 위 표에 추가합니다.
- 섹션: **상태**(제안 / 적용 중 / 진행 중 / 대체됨) · **맥락**(왜 필요했나) · **결정**(무엇을 어떻게) · **결과**(얻는 것과 감수하는 것). 해당하면 **기각한 대안**·**다시 볼 조건**을 더합니다.
- 결정과 근거처럼 바뀌지 않는 내용만 적습니다. 할 일·진행 상황은 이슈나 PR에 둡니다.
- 결정을 뒤집을 때는 기존 파일을 고치지 않고 새 문서를 만든 뒤, 기존 문서 상태를 "대체됨 → 새 문서 링크"로 바꿉니다.
