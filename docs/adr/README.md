## 작성 방법

새 결정은 직관적인 한글 파일명으로 추가하고 이 표를 갱신합니다. 섹션은 네 개를 사용합니다:
**상태** (제안/적용 중/진행 중/대체됨) · **맥락** (왜 결정이 필요했나) · **결정** (무엇을 어떻게) · **결과** (얻는 것과 감수하는 것).

결정을 뒤집을 때는 기존 파일을 고치지 않고 새 문서로 대체하며, 기존 문서의 상태를 "대체됨 → 새 문서 링크"로 바꿉니다.
